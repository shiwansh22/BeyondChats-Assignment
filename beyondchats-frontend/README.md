# BeyondChats Frontend

Minimal Next.js + TypeScript frontend to display articles from a Laravel backend.

## Setup
1. Install dependencies: `npm install`
2. Set API base URL:
   `NEXT_PUBLIC_API_BASE_URL=http://localhost:8000/api`
3. Run: `npm run dev`

## Scope
This frontend intentionally focuses only on:
- Listing articles
- Viewing original and updated article content

Admin features, search, pagination, and authentication were excluded to prioritize core requirements within time constraints.
